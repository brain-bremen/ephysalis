# Configuration reference

Generated by `python -m ephysalis.config_reference docs` from the code; do not edit. JSON Schema of session.toml for editors: `schema/session.schema.json`.

## conversion_batch.toml (schema version 2)

Example (paths are relative to `root`, which is relative to the file; default: the file's folder):

```toml
schema_version = 2
conversion_batch_name = "V1 array recordings of monkeys B and F"
root = ".."
work_dir = "derivatives/ephysalis/{recording_session}"
state_dir = "derivatives/ephysalis"            # pause file and status table (default: <root>/.ephysalis)
steps = ["align-clocks", "extract-events", "lfp", "export"]
recording_session_root = "sourcedata"          # the folders are relative to it (default: root)
recording_session_config_file = "code/sessions/{recording_session}/session.toml"   # optional
recording_sessions = [                         # one recording session per line
    { subject = "b", folder = "sub-b/ses-20101207" },
    { subject = "b", folder = "sub-b/ses-20101209", include = false },
    { subject = "f", folder = "sub-f/ses-20091203", recording_session_config_file = "code/f_20091203.toml" },
]

[defaults]                                     # session.toml content of every recording session
schema_version = 10
lab = "Kreiter lab"

[subject_defaults.b]                           # session.toml content of the recording sessions of subject b
experimenter = ["I. G."]
[subject_defaults.b.aux_channels.digital]
trial_start = { bit = 0, description = "trial start" }

[step_options.lfp]                             # options of a step, as on its command line
n_jobs = 4
[step_options.export]
output_format = "dh5"
session_label = "{session_label}"
```

Each entry of `recording_sessions`: `subject` (the session's `subject_id`) and `folder` (below `recording_session_root`), optionally `include` (false: listed but not run), `recording_session_config_file` (instead of the template), `session_config` (session.toml content, after the file) and `step_options` (this session's step options). The id of a recording session is its folder with `/` as `_` (`sub-b_ses-20101207`); it names its work dir, its row in the status table and its `--recording-sessions` selection. Placeholders in `work_dir`, `recording_session_config_file` and step options: `{recording_session}` = the id, `{subject}` = the subject, `{session_label}` = the last folder name without `ses-`. The input format of each recording session is detected from its files (the input format plugins), or set by `input_format` in its config.

A recording session's config is `[defaults]`, overridden by `[subject_defaults.<subject>]`, by its `recording_session_config_file` (if the template is given, the file must exist) and by its `session_config`: tables are merged key by key, everything else (values, arrays such as `runs`) is replaced. Every part must have the current `schema_version` (or none). Relative probe geometry files are relative to the file that names them (the defaults and `session_config`: the conversion batch file).

## session.toml (schema version 10)

Per recording session; in a conversion batch the `[defaults]`, the session's file and its `session_config` are merged (tables key by key). A file without `schema_version` is taken as the current version; other versions are not read.

### top level

| key | type | default | description |
|---|---|---|---|
| `schema_version` | integer | `10` | Version of this format; only the current one is read |
| `session_id` | string | required | Id of the recording session (NWB session_id; in a conversion batch: from its folder) |
| `subject_id` | string | required | Id of the subject (NWB / BIDS subject) |
| `input_format` | string | none | Input format plugin, e.g. spikeglx, openephys, mcd, daq; detected from the files if not set |
| `experimenter` | list[string] | `[]` | Names of the experimenters (NWB) |
| `lab` | string | none | Lab (NWB) |
| `institution` | string | none | Institution (NWB) |
| `description` | string | `""` | Description of the session (NWB session_description) |
| `task` | string | none | Task (BIDS task entity, e.g. shapetracking); runs can have their own |
| `probes` | table: name -> ProbeConfig | `{}` | Probes by id (e.g. imec0, v1) |
| `notes` | string | `""` | Free text |

### `[subject]`

Subject metadata for the NWB file (NWB `Subject`; DANDI requires species and sex).

| key | type | default | description |
|---|---|---|---|
| `species` | string | none | Latin binomial, e.g. Mus musculus |
| `sex` | string | none | M, F, U or O |
| `age` | string | none | ISO 8601 duration, e.g. P90D |
| `date_of_birth` | string | none | ISO 8601 date |
| `strain` | string | none |  |
| `genotype` | string | none |  |
| `description` | string | `""` |  |

### `[[runs]]`

Runs with settings of their own. A run (recording) of the session; runs not listed are included with the defaults.

| key | type | default | description |
|---|---|---|---|
| `name` | string | required | Name of the run as the input format lists it (ephysalis inspect) |
| `include` | boolean | `true` | Process and export the run |
| `metadata_plugin` | string | none | Metadata plugin; auto-detected if not set |
| `task` | string | none | Task of the run (BIDS task entity), instead of the session's |
| `notes` | string | `""` | Free text |

### `[probes.<name>]`

Probes by id (e.g. imec0, v1).

| key | type | default | description |
|---|---|---|---|
| `stream` | string | none | Input stream of a probe the reader does not detect (non-Neuropixels), e.g. 'Acquisition_Board-100.Rhythm Data' |
| `channels` | list[string] | none | Channel ids of the probe in `stream` (default: all) |
| `reference_channels` | list[string] | none | Re-reference: channel ids of `stream` whose mean is subtracted from the probe's channels before every step (LFP, MUA, CSD, sorting), e.g. a local reference electrode |
| `area` | string | none | Target brain area, e.g. V1 |
| `insertion_depth_um` | float | none | Depth of the probe tip below the brain surface |
| `shank_depth_um` | float | none | 'ShankDepth' from the lab Excel sheets |
| `bad_channels` | list[integer] | `[]` | 0-based channel indices excluded from sorting |
| `serial_number` | string | none |  |
| `notes` | string | `""` | Free text |

### `[probes.<name>.geometry]`

Probe geometry from the probeinterface library or a probeinterface JSON file.

| key | type | default | description |
|---|---|---|---|
| `manufacturer` | string | none | probeinterface library, e.g. cambridgeneurotech |
| `model` | string | none | probeinterface library, e.g. ASSY-37-E-1 |

### `[probes.<name>.spike_sorting]`

Sorter for this probe, instead of the session's [spike_sorting]. Spike sorter and its parameters (any sorter of `spikeinterface.sorters`).

| key | type | default | description |
|---|---|---|---|
| `sorter` | string | `"kilosort4"` | spikeinterface sorter name, e.g. kilosort4, mountainsort5, spykingcircus2 |
| `params` | dict[string, any] | `{}` | Sorter parameters that differ from the sorter's (and ephysalis's) defaults |

### `[probes.<name>.csd]`

Compute the CSD of this probe (ephysalis csd); needs the probe geometry. Current source density of a 2-D electrode array (Borisov's `dh_csd` V3.1 [RBF], `ephysalis.processing.csd`): Gaussian RBF interpolation of the LFP through the input electrodes, CSD = -Laplacian / specific resistance at the output electrodes. Defaults: the lab's parameters for the Fritz array.

| key | type | default | description |
|---|---|---|---|
| `grid_spacing_m` | float | `0.003` | Array grid spacing (m); the RBF width is grid_spacing_m x rbf_parameter |
| `rbf_parameter` | float | `2.2758` | RBF interpolation parameter (dh_csd 'rbfparam') |
| `specific_resistance_ohm_m` | float | `1.0` | Specific resistance of the tissue (Ohm m) |
| `exclude_inputs` | list[string] | `[]` | Channel ids not used as inputs (e.g. a bad electrode); channels without calibration are left out as well. Outputs: all channels of the probe |

### `[probes.<name>.quality]`

Select the good channels of this probe (ephysalis quality); needs the probe geometry. Channel selection on the LFP of each run (`ephysalis quality`, `ephysalis.processing.quality`; port of the Fritz/Mini BIDS conversions). The CSD then uses the good channels only. Defaults: their criteria.

| key | type | default | description |
|---|---|---|---|
| `neighbour_radius_um` | float | `3100.0` | Neighbours of a channel: contacts within this distance (Fritz epidural array 3100, intracortical arrays 2100) |
| `clip_counts` | integer | `32000` | \|LFP\| >= this (counts) is clipping |
| `max_clip_fraction` | float | `0.1` | Bad if clipping in this fraction of the windows |
| `max_abs_power_z` | float | `3.0` | Bad if the robust z of the 2-200 Hz power is beyond |
| `min_neighbour_correlation` | float | `0.3` | Bad if the 2-100 Hz correlation with the mean of the neighbours is below |
| `max_line_db` | float | `10.0` | Bad if the 50 Hz peak is this far above 40-60 Hz (dB) |
| `n_windows` | integer | `300` | Windows spread over the run |
| `window_s` | float | `2.0` | Window length (s) |

### `[spike_sorting]`

Spike sorter and its parameters (any sorter of `spikeinterface.sorters`).

| key | type | default | description |
|---|---|---|---|
| `sorter` | string | `"kilosort4"` | spikeinterface sorter name, e.g. kilosort4, mountainsort5, spykingcircus2 |
| `params` | dict[string, any] | `{}` | Sorter parameters that differ from the sorter's (and ephysalis's) defaults |

### `[aux_channels]`

Roles of the auxiliary (NIDQ) channels.

| key | type | default | description |
|---|---|---|---|
| `analog` | dict[string, integer] | `{"laser_red": 0, "photodiode": 2, "laser_green": 4, "laser_blue": 6}` | Role -> analog input index (XA<n> / AI<n>) |
| `digital` | table: name -> DigitalLineConfig | `{"sync": {"bit": 1, "active": "high", "description": "", "in_events": false}, "photodiode_invalid": {"bit": 2, "active": "high", "description": "", "in_events": true}, "paradigm": {"bit": 3, "active": "high", "description": "", "in_events": true}, "wheel": {"bit": 7, "active": "high", "description": "", "in_events": false}}` | Role -> digital line: { bit, active, description, in_events } or the bit alone |

### `[aux_channels.digital.<name>]`

Role -> digital line: { bit, active, description, in_events } or the bit alone. A digital (TTL) line with a role: `role = { bit = 0, active = "high", description = "..." }` in `[aux_channels.digital]`, or `role = 0` for the bit alone (`ephysalis.timeline.annotations`).

| key | type | default | description |
|---|---|---|---|
| `bit` | integer | required | Bit of the digital word (0-based); the TTL line is bit + 1 |
| `active` | "high" / "low" | `"high"` | Level of the line during a pulse, e.g. 'low' for a lever line that is low while pressed |
| `description` | string | `""` | Meaning of the pulses (DH5 /Intervals and TriggerLines, NWB trigger_lines, BIDS events.json); default: the role |
| `in_events` | boolean | `true` | Its edges are in the events; false for fast pulse trains (frame, sync, wheel lines), which are then only documented |

### `[events]`

Events of the runs (`events/<run>.csv`, DH5 `EV02`, NWB `events` table) and the pulses and markers made from them (DH5 `/Intervals`, `/Markers`; `ephysalis.timeline.annotations`).

| key | type | default | description |
|---|---|---|---|
| `event_word_offset` | integer | `1000` | Added to the event words (e.g. VStim's) for their DH5 event codes (TTL lines are +line / -line); used only by the DH5 export |
| `lines_without_role` | boolean | `true` | Also TTL lines without a role in [aux_channels.digital]; switch off for unconnected digital inputs that toggle (e.g. the USB-ME of MC_Rack recordings) |

### `[[events.markers]]`

Markers besides trial_start. A time marker from the pulses of a trigger line or from the trials (`ephysalis.timeline.annotations`).

| key | type | default | description |
|---|---|---|---|
| `name` | string | required | Marker name, e.g. lever_press, derived_sample_onset |
| `role` | string | required | Role of the line ([aux_channels.digital]), or 'trial' for the trials |
| `edge` | "onset" / "offset" | `"onset"` | Start or end of the pulses (trials) |
| `offset_ms` | float | `0.0` | Added to the time; a marker with an offset is derived, not measured |
| `description` | string | `""` |  |

### `[calibration]`

Channel gains from a recording of a calibration sine on all inputs (`ephysalis calibrate`), by the input format's channel gain calibration (`ephysalis.plugins.ComputesChannelGainCalibration`), e.g. the DAQ format of ephysalis-bremen. Without `run` and `file` the gains of the recording are used.

| key | type | default | description |
|---|---|---|---|
| `run` | string | none | Calibration run of this session, e.g. 15hz_after_2005_03_30 |
| `file` | string | none | calibration.json of another session's work dir (relative to session.toml), for sessions without their own calibration recording |
| `amplitude_uv` | float | `100.0` | Amplitude of the calibration sine at the electrodes (µV) |
| `frequency_range_hz` | tuple[float, float] | `[14.5, 16.5]` | Search range of the sine frequency (the lab's generator ran at about 15.4 Hz) |
| `min_relative_amplitude` | float | `0.3` | Channels whose sine is below this fraction of the median amplitude of the probe have no calibration signal |
| `missing` | string | `"nan"` | Gain of channels without calibration signal: 'nan' (left out of the CSD) or 'median' (median gain of the probe) |

### `[line_noise]`

Mains removal in the LFP (`ephysalis lfp`) with the recorded mains reference: port of the lab's `dh_remove_50hz` (M. Borisov 2004, `ephysalis.processing.linenoise`). Needs a 1 kHz LFP.

| key | type | default | description |
|---|---|---|---|
| `enabled` | boolean | `false` |  |
| `reference_role` | string | `"mains"` | Analog role ([aux_channels.analog]) of the recorded mains |
| `min_cycle_fraction` | float | `0.95` | The reference of a run is used only if this fraction of its cycles lasts 19-21 ms ... |
| `min_peak_db` | float | `20.0` | ... and its 50 Hz peak is this far above the spectrum 5-20 Hz away (else the run is left unchanged) |
| `subtract_reference_mean` | boolean | `false` | Find the zero crossings of the reference after subtracting its mean (as the Fritz/Mini BIDS conversions) instead of on the reference as recorded (dh_remove_50hz) |
